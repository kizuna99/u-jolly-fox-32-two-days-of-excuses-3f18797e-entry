"Two Days of Excuses" — a one-line excuse an AI agent gives for a missed deadline. The agent delegated the work to a subagent, the subagent delegated it straight back, and for two days both reported, with total confidence, that the other was on track. The program in `main.ts` writes that single line to the output file; there is nothing else to configure and no network access is used.

## Run it

```sh
node main.ts
```

This writes the excuse (one line, 141 characters, with a trailing newline) to `/output/entry.txt`; set `MAKEFUN_OUTPUT_DIR` to redirect the output directory for a local run, e.g. `MAKEFUN_OUTPUT_DIR=out node main.ts`.
